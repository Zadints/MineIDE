  <h1>MineIDE </h1>
</div>

MineIDE is an integrated development environment (IDE) built using Java and JavaFX, designed for the creation, configuration, and management of Minecraft server projects. It allows users to configure Minecraft versions, select server software and JDK versions, and automate project setup and file management. Its architecture is based on the principles of Clean Architecture, aiming for a clear separation of responsibilities, maintainability, and ease of extensibility.
